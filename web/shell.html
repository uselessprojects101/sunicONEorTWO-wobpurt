Sonic 2 (2013) – Web Port

This site contains no game data. To play, choose your own Data.rsdk from your copy of Sonic 2 (2013). The file is read inside your browser only and is never uploaded.

Click to choose Data.rsdk or drag and drop it here

Your Data.rsdk is stored in this browser from last time.

Your Data.rsdk and save files are kept in this browser (IndexedDB) so you don't have to pick the file every time.
