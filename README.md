# sunicONEorTWO-wobpurt
This is a port of RSDKv4 to the web, allowing you to play Sonic 1 and Sonic 2's respective RSDK's on the web.

This is just an attempt, and I may or may not update this to my liking, or to fix bugs.

YOU NEED THE "data.rsdk" OF EITHER SONIC 1 OR 2 IN ORDER TO RUN THIS! 

# ISSUES KNOWN AS OF NOW:
1. The save files are combined between Sonic 1 and 2, which may cause minor to major issues.
2. No way to get to debug mode enabled.
3. Versus mode doesn't work, will attempt to add multiplayer one day.
4. Main Menu's shading is not present, which doesn't affect anything, much more a personal preference.
